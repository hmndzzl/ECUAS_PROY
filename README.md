# Proyecto Final de Ecuaciones Diferenciales

**Métodos de Runge--Kutta (RK2 Heun y RK4)**

## Autores:
Diego Calderón - 241263 | Pedro Caso - 241286 | Hugo Méndez - 241265

## Descripción General

Proyecto que implementa los métodos RK2 Y RK4 para resolver: - EDO primer orden - EDO segundo orden no
homogénea - Sistema lineal 2×2 - Sistema no lineal (péndulo) -
Comparación analítica - Convergencia y gráficas

## Lenguaje

Python 3.10+

## Dependencias

    pip install numpy 
    pip install matplotlib

## Ejecución

    python proyecto_final.py o Python3 proyecto_final.py
